👗 Fashion House — Clothing Store Management System | C++

I developed Fashion House, a console-based clothing store management system designed to simulate a real-world fashion store and online shopping experience.

🛍️ Key Features:

- Product management with IDs, categories, sizes, colors, prices, and stock.
- Product search and category filtering.
- Shopping cart and quantity management.
- Discount and delivery fee calculation.
- Customer information and multiple payment methods.
- Checkout and invoice generation.
- Unique order IDs and order history.
- Automatic stock updates after purchases.
- Order cancellation with stock restoration.
- Low-stock monitoring and store statistics.
- Sales and inventory calculations.

💻 The project was built using C++ fundamentals, including arrays, loops, conditions, strings, functions, and basic data management — without using OOP.

🎯 This project helped me practice building a complete business-oriented system while improving my problem-solving, logical thinking, and programming skills.
